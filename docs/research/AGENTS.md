# `docs/research`

Write-ups of a question researched before a change was made: `skinning.md` (whether a solver could skin the procedural models, issue #85), `ik.md` (full-body IK: what went in and how it was measured) and `webgpu.md` (what moving to `WebGPURenderer` would take, and what three's meshlet pipeline would buy: an estimate, not a port). They record the state when written; the code and its AGENTS.md files say what holds now.

The rules across the game are the [root AGENTS.md](../../AGENTS.md).
