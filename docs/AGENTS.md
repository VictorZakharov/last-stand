# `docs`

Writing about the game that isn't code.

The rules across the game are the [root AGENTS.md](../AGENTS.md); each directory under this one has an AGENTS.md of its own.

- `agents/`: notes for agents on the heroes' models and legs, too long for an AGENTS.md.
- `research/`: write-ups of a question researched before a change (skinning, full-body IK).
- `screenshots/`: the README's pictures, the one place pictures may be committed.
