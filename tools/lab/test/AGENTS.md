# `tools/lab/test`

The lab's unit tests (`npm run lab:test`, `node --test`, a second; the PR build runs them): the command line, the verdicts, the server's checks, the source maps, a check's jobs, co-op's link and judge, and the page's pure helpers (flashes, patches). A test file is named after the module it tests.

The rules across the game are the [root AGENTS.md](../../../AGENTS.md), the lab's own [`tools/lab/AGENTS.md`](../AGENTS.md).
